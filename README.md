# Agentic Software Engineering Portfolio

## Course Introduction

This repository contains my activities and learning progress in Agentic Software Engineering. This course introduces how artificial intelligence can be used in software development to perform tasks, make decisions, and solve problems. It also discusses the importance of teamwork, Agile methods, version control, and responsible AI development.

As a Computer Engineering student, I want to understand how AI agents work and how they can be applied to real-world systems. This portfolio will serve as a record of the knowledge and skills I develop throughout the course.

## Personal Learning Goals

My learning goals for this course are:

1. Understand how AI agents make decisions and perform tasks.
2. Learn how to use Git and GitHub to manage software projects.
3. Improve my programming and problem-solving skills.
4. Understand how Agile development helps teams build better software.
5. Learn how to develop AI systems that protect user privacy and safety.
6. Apply my knowledge to future Computer Engineering projects.

## Reflection from Part A

After completing Part A, I learned that Agentic Software Engineering is not only about making software more intelligent. It is also about understanding how AI systems behave and how developers can control their actions.

One important lesson I learned is that AI agents are different from traditional applications because they can choose actions based on their goals and available information. However, this ability also creates risks, especially when AI makes incorrect decisions.

I also realized that Agile development is useful because AI systems need continuous testing and improvement. Developers should not depend completely on automation because human judgment is still important.

For me, the main purpose of Agentic Software Engineering is to create systems that can help people while remaining safe, reliable, and responsible.
